# The Question Log is anonymous and shown only in aggregate

Students log in, but their identity is used only for access, for the Cohort and for usage limits. The Question Log has no link to a student at all: no name, no email, no pseudonym. Usage is counted separately and is never stored with the questions. Each entry holds only the question text with any pasted code removed, a topic classification and the Sources used. Students are told this in the interface. Teachers see aggregates and Unanswered Questions, never who asked. Entries are deleted a fixed time after the Cohort ends (initially 30 days). Conversations exist only while the browser tab is open.

We chose anonymous over pseudonymous because in a class of about 30 that the teacher knows, a stable pseudonym is easy to re-identify from question patterns. We also chose it because students who know the teacher can see who asked will ask fewer questions. The cost is that per-student follow-up ("who is struggling?", "how many distinct students asked about X?") is deliberately impossible and can't be added retroactively.

## Retention of personal data

Only two things hold personal data: the Roster (school email addresses) and each Student's usage count. The usage count covers only the current day and is overwritten, so there is no history. The Roster is deleted together with the Question Log, 30 days after the Cohort ends.
